## 2️⃣ 원본 전략 구조 (사용자 제시·확정 그대로)

- **차트 주기:** 신호 **M5** (진입·캔들 규칙). 구조 필터 **H1**. (입력으로 주기 변경 가능)
- **통화쌍·상품:** 사용자 심볼 입력. 기본값 **`US100`** (브로커에 따라 `USTEC`, `XAUUSD` 등 수동 변경). 브로커 **Point·시간 자동 감지**.
- **진입 조건:**
  - **아시아 세션** 구간 고저(레인지) 산출 (브로커 서버 시각, 사용자 조정 가능).
  - **런던/NY 거래 허용 구간** 내 M5 **종가**가 레인지 상단(매수) 또는 하단(매도)을 버퍼 포인트 포함 돌파.
  - **H1** 종가가 EMA(기본 50) 위(매수) / 아래(매도) — 기관 방향 정합.
  - 돌파 후 **M5 풀백**: 직전 완성봉이 EMA(기본 20) 터치 후 방향 캔들 확인.
  - **Quality Engine** 점수 ≥ 당일 동적 임계 (자가학습·일일 최소 진입 하한과 연동).
- **캔들 조건:**
  - 매수: M5 완성봉 `Close > Open` (양봉 확인).
  - 매도: M5 완성봉 `Close < Open` (음봉 확인).
- **보조 필터:**
  - 스프레드 상한(포인트), SL Guardian(스톱레벨·스프레드·금요일·롤오버).
  - **뉴스: Guardian만** — 고영향 구간(사용자 시간창 + 스프레드 급등) 시 **신규 진입만** 보수화(SL 버퍼 확대), 완전 차단 기본 OFF.
  - 일일 손실 %, 총 손실 %, 일 최대/최소 거래 수.
- **SL/TP 규칙:**
  - SL: 스윙(최근 N봉) ± **SL_BufferPoints** (+ 뉴스 Guardian 추가 버퍼).
  - **TP 없음(0)** — 수익은 **트레일링 최우선** (기본 **200 / 200 / 10** 포인트).
  - 트레일: 이익 **TrailStart** 도달 시 SL → 진입가±**TrailLock**; 이후 **TrailStep** 스텝 추격.
- **진입 제한 규칙:**
  - **한 캔들 한 진입** (M5 바 단위).
  - **동일 심볼·매직 오픈 포지션 존재 시 신규 진입 금지** (청산 전 재진입 없음).
  - 일일 손실%/총 DD% 도달 시 신규 진입 금지 (청산·트레일은 유지).
