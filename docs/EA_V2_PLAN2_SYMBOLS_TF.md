## 2. 왜 이 3종목인가 (안2·안정 균형)

### 2.1 선택 원칙

1. **REG와 PULL을 다른 자산군에 배치** → 한 날 한 패턴이 막혀도 다른 종목·패턴으로 **0건일 완화**.  
2. **스프레드·슬리피지**가 월 분산에 직결 → 지수는 **1종·PULL만**, FX는 **REG 전용 1메이저**.  
3. 선택표 S3 종목(**EURUSD·골드**) + S2와 양립 가능한 **US100**(변동·세션 유동성) 조합.

### 2.2 종목별 역할

| 종목 | 패턴 | 비중(체결 목표) | 안정 근거 |
|---|---|---:|---|
| **EURUSD** | **REG only** | ~35% | 스프레드 상대 최저(표 FX 25pt), H1 횡보 빈도 높음, VWAP 회귀 해석 명확 |
| **XAUUSD** | **REG only** | ~30% | 선택표 S3 골드 축, KST 저녁 변동·세션 VWAP 이탈 빈번, **어제 S1 무진입과 무관**한 별 패턴 |
| **US100** (NAS100·USTEC 별칭) | **PULL only** | ~35% | 지수 1종만 — US30/US500 대비 **스프레드·갭 상대 양호**, M15 임펄스·H1 추세가 S2형 눌림과 맞음 |

### 2.3 안2에서 빼는 종목 (의도적 제외)

| 제외 | 이유 |
|---|---|
| **US30, US500** | 포인트·스프레드·추격 이탈(S1 로그 **추격X** 다발) → **월 CV·PULL 손익 분산** 악화 |
| **DE30/DE40** | H1 역추세·세션 비대칭, 어제 로그 **H1X** 다수 → 안2 목적과 불리 |
| **EURUSD 이외 FX** | REG 1종으로 **상관·학습 파일 단순화** (GBPUSD는 후속 옵션만) |
| **골드에서 PULL** | M15 임펄스 SL 폭 과대 → **0.24% PULL 랏**에도 손절 거리·스프레드/SL 비율 불리 |
| **지수에서 REG** | 지수 VWAP 이탈은 **추세장에서 가짜 회귀** 많음 → 안정 KPI 저하 |

### 2.4 브로커 심볼 (마켓워치)

- 골드: `XAUUSD` / `GOLD` / 접미사 `_i`, `.pro` → EA **BaseName** 자동 (IDC_R와 동일 계획).  
- 지수: `US100`, `NAS100`, `USTEC`, `NDX` 중 **1개만** 마켓워치·스캔.  
- **동일 지수 복수 심볼**은 스캔 제외 (이중 후보·이중 리스크 방지).

## 3. 타임프레임 상세

### 3.1 계층 구조

```
[부착 차트 TF]  ← 표시·로그용 (권장 M5)
       ↓
[신호 TF = M5]  ← 닫힌 봉 shift=1 만 진입 판단 (IDC_R 동일)
       ├─ REG: VWAP 괴리, 꼬리, ATR(14) 품질, 추격
       └─ PULL: M15 임펄스 탐지 후 M5 첫 눌림 확인
[H1]            ← REG: 횡보(EMA평탄/ADX). PULL: 종가 vs EMA50 방향
[M15]           ← PULL만: impulse bar (body/range), pullback open
```

### 3.2 권장 입력값 (V2 구현 시)

| 입력(가칭) | 값 | 설명 |
|---|---:|---|
| `InpSignalTF` | **5** | M5. **변경 비권장** (안2 전 패턴 공통) |
| `InpTrendTF` | **60** | H1 추세·횡보 |
| `InpStructureTF` | **15** | PULL 구조 (M15) |
| `InpEmaPeriod` | **50** | H1 EMA |
| `InpAtrPeriod` | **14** | 신호봉·H1 ATR (M5/H1 각 적용) |
| `Period()` 부착 | **5** | **M5 권장** — O/X·캔들 로그와 실제 신호봉 일치 |

### 3.3 부착 TF별 동작 (IDC_R 검증 패턴 재사용)

| 차트 TF | 실행 | 비고 |
|---|---|---|
| **M5** | 신호=표시 **동일** | **최적** — 디버그·수동 확인 용이 |
| M1 | 신호는 **M5** 고정 | 틱 밀도만 ↑, 전략 동일 |
| M15 | 신호는 **M5** 고정 | 차트와 신호 불일치 → 로그만 헷갈릴 수 있음 |
| H1 | 신호는 **M5** 고정 | 부착 비권장 |

**원칙**: 안2도 S1과 같이 **「차트 TF ≠ 신호 TF」** — 공식은 **M5 종가 + H1 컨텍스트**.

### 3.4 세션·봉 시계

- **진입 윈도**: KST **16:00–00:30** (종목 무관 동일).  
- **VWAP 리셋**: KST **16:00** (REG).  
- **아시아 레벨**: 안2 **REG는 아시아 고저 미사용** (VWAP만).  
- **판정 시각**: M5 **닫힌 1번 봉**만 (형성 중 0봉 진입 없음).

## 5. 마켓워치·EA 입력 체크리스트

1. 마켓워치: **EURUSD, XAUUSD, US100(1개 별칭)** 만.  
2. `InpUseGold` / `InpUseIndex` / `InpUseFX`: V2에서 **안2 프로파일** = FX+Gold+Index(US100만 화이트리스트).  
3. EA **한 차트에 부착** (권장 **XAUUSD M5**) → 30초마다 스캔으로 3종 동시 감시.  
4. **멀티 차트에 EA 복수 부착 금지** (매직·학습 파일 충돌).
