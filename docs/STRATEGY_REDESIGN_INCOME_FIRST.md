# 전략 재설계안 — **월 300만원 하한 최우선** (코드 없음 · 컨펌 대기)

**검수·설계 차수:** 수익 목표 재정렬 **1차 설계 제출** (코드 제출 금지 준수)

---

## 0. 최우선 목표 (교수님 명령 고정)

| 항목 | 수치 |
|------|------|
| 계좌 | 프랍 **$100,000** (FundedNext Stellar 2 기준) |
| **월 순수익 하한** | **₩3,000,000** (실패 = 전략 불합격) |
| 환산 (검산용) | ₩3,000,000 ÷ 1,350 ≈ **$2,222/월** → **월 +2.22%** |
| 부가 목표 | 일 **≥2진입**, 트레일 **최우선**, 자동화, 자가학습, 프랍 생존 |

**원칙:** 생존·품질·Guardian·기관 회피는 **월 +2.22%를 넘기기 위한 제약**으로만 설계한다.  
이 하한을 수학적으로 못 채우는 조합은 **제외**한다.

---

## 1. 수익 역산 (설계 입력값)

가정: 월 **20거래일**, 일 **2~4진입** → 월 **40~80건**.

| 케이스 | 월 거래 | 계좌 대비 월 목표 | **건당 기대 기여(평균)** |
|--------|---------|-------------------|--------------------------|
| A | 40건 (일 2) | +2.22% | **+0.056%/건** (자본 기준) |
| B | 60건 (일 3) | +2.22% | **+0.037%/건** |
| C | 80건 (일 4) | +2.22% | **+0.028%/건** |

리스크 **0.5%/건**(손절 시)일 때 필요 **기대 R** (단순 근사):

- 월 40건, 이길 때 평균 **+1.5R**, 질 때 **-1R**, 승률 **p**  
  → 월 기대 ≈ `40 × 0.5% × (p×1.5 - (1-p)×1)` = **2.22%**  
  → **p ≈ 54%** (트레일로 평균 이익 R을 1.8~2.5로 올리면 p는 더 낮아져도 됨)

**설계 결론**

1. **일 2회만**으로 가려면: **트레일 평균 R ≥ 2.0** 또는 **승률 50%+** + 변동성 큰 세션 필수.  
2. **품질 필터로 빈도 줄이면** → 리스크%·평균 R을 올리거나 **목표 불가** → **거절**.  
3. **$100k, 월 ₩300만** = **공격적이지만 프랍 일손실 4~5% 안에서 가능한 구간** → **리스크는 고정 0.5%가 아니라 0.5~1.0% 가변(품질·변동성 상한)** 으로 **목표에 맞춘다**.

## 3. 제출안 — **B′ (Income Session Flow)** 권장

기존 안 B 뼈대(세션 레인지 → 돌파 → H1 → M5 풀백)는 유지하되, **이름·로직·파라미터 철학을 “수익 역산형”으로 교체**.

### 3.1 컨셉

**런던+NY 중첩 구간**에서만, **아시아 레인지 돌파 후 첫 변동성 확장**을 **한 방향으로만** 잡고, **TP 없이 트레일**로 **R 2~4**를 노린다.  
기관 오픈 플로우 **편승**(원래 B). 예측 최소, **이미 나온 방향만**.

### 3.2 진입 (요약)

1. 아시아 고저 확정(세션 종료 후).  
2. **거래 허용:** London Open ~ NY Mid (기본 08:00–18:00 서버, **전부 입력**).  
3. M5 종가 돌파(+버퍼) + H1 EMA(50) 동방향.  
4. **풀백:** M5 EMA(20) **또는** 돌파구간의 **50% 되돌림** (수익형 — 깊은 되돌림도 잡음).  
5. **Quality:** 점수 **하한은 목표 빈도에 연동** — 일 2회 미만이면 **임계 완화**, 단 **Degrade·일DD**는 유지.  
6. **한 봉 1진입, 포지션 중 재진입 금지** (원 명령 유지).

### 3.3 청산 (수익 핵심)

- SL: 스윙 ± 버퍼 (포인트).  
- TP: **0**.  
- 트레일: **200 / 200 / 10** (기본, 포인트).  
- **목표:** 이평 **+2.0R/건** 이상이 되는 변동 구간만 거래 (변동성 필터 **ATR 백분위 ≥ 중간**).

### 3.4 리스크·랏 (수익 역산)

| 모드 | 규칙 |
|------|------|
| Base | Balance의 **0.6%**/건 (입력 상한 **1.0%**) |
| Scale | Quality 상위 20%만 **0.8~1.0%** |
| 하한 | **0.35%** (연속손실 시, **일목표 미달 시 상향 금지**) |

일 손실 **4%** 도달 → 당일 종료. **총 9%** → EA 정지.  
→ **월 2.22%**는 **정상 국면 3~5주에 달성**, **최악 달은 목표 미달 가능** (통계·과거데이터로 검증 필수, 허위 단정 금지).

### 3.5 자가학습 (수익 목표 연동)

- 청산마다: R배수, 세션, MFE/MAE 저장.  
- **세션별 기대 R**이 하락하면 해당 세션 **OFF** (생존 아님 **수익 최적**).  
- **목표 추적:** `월 누적 %` vs `2.22%` — 15일 경과 시 **50% 미만**이면 Quality 완화·허용 세션 확대 (DD 한도 내).

### 3.6 기관/AI

- M1 브레이크 경쟁 회피 → **M5**  
- 홀딩 **30분~4시간**  
- 오픈 레인지 **편승**
