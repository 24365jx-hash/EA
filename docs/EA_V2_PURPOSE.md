# 신규 EA — 최초 목적 정리 (교수님 요청 · 2026-11-26)

질문 양식이 생략되었으므로, **저장된 헌법·선택표·실계 로그·최근 지시**만으로 목적을 고정합니다. 아래에 **가정(교정 가능)** 을 명시합니다.

---

## 1. 교수님 최초 목적 (변하지 않는 축)

| 순위 | 목적 | 출처 |
|:---:|---|---|
| 1 | **상업용 수준 MT4 EA** — `#property strict`, 브로커·FTMO 실계에서 오류 131/134·가짜 UI 없이 자동 매매 | 헌법 4절, 검수 프로토콜 |
| 2 | **FTMO 2단계 스탠다드 10만 달러** 생존 — 회사 한도 내 **EA 소프트** 일손실 2%, 에쿼티 바닥 93%, 서버 차단·세션·주말 규칙 | 헌법, 선택표 3절 |
| 3 | **현금흐름(인출 가능 소득)** — 설계표 기준 **월 중앙 실수령 300만원 이상**을 넘기는 쪽(학습 전 410만·후 510만은 S1 시뮬 목표). **수익 보장 아님** | 선택표, 헌법 4절 |
| 4 | **자기학습 Layer** — 진입 공식과 분리, 청산 후 가중치·점수·랏 기울기·트레일 프리셋. 터미널 재시작 후 파일 복구 | 헌법 L1~L6 |
| 5 | **운영 투명성** — 디버그 시 게이트·진입조건 O/X, 부착 TF 표시. 존댓말·검수 보고 가능 | L6, 대화 이력 |
| 6 | **리스크** — 거래당 평균 **0.30%**, 상한 **0.40%**; 수동/자동 랏, 최소랏 미달 시 진입 취소(리스크 확대 금지) | 헌법 |

## 2. 교수님이 새로 고정하신 축 (S1 폐기 사유)

| 항목 | S1 (IDC_R) | 신규 (V2) |
|---|---|---|
| **일일 진입** | 목표 2회, **평균 1.8**, **0건일 허용** | **거래일(세션 가동일)당 실 체결 ≥ 2건**을 **1순위 운영 KPI** |
| **빈도 vs 품질** | 「조건 미달 신호를 만들어 넣지 않는다」 | KPI 충족을 위해 **사전에 정의된 복수 신호 패밀리**로 **기대 빈도를 설계** (임의 완화·랜덤 진입은 금지) |
| **전략 본체** | S1 유동성 재흡수 단일 | **폐기** → V2 신규 헌법 |

**가정 (교수님 미응답 시 적용)**: 「2개 이상」= **하루 실제 주문 체결 2건 이상**. 주말·EA 미부착·일손실/7% 소프트 스톱·FTMO 금지 구간은 제외.

**한계 (정직한 전제)**: 어떤 전략도 **모든 달력일 100% 보장**은 불가능합니다. V2는 (① **독립 신호 2종 이상**, ② **4~6종목 병렬**, ③ **세션 중 2차 슬롯 재진입 규칙**)으로 **0·1건일 확률을 설계상 최소화**하는 것을 목표로 합니다.

---

## 3. S1과 목적의 어긋남 (한 줄)

S1은 **월 소득 중앙값**에 최적화된 **저빈도·고손익비** 재흡수였고, 교수님 운영 기대는 **최소 일 2체결**입니다. 어제 5종목·전 게이트 정상인데 0건인 날은 S1에게 **정상**이지만, 교수님 KPI에는 **실패**입니다.

---

## 4. V2에서 유지·버릴 것

**유지 (인프라)**  
FTMO 리스크 캡, KST 세션(기본 16:00–00:30), 포인트 프리셋, 멀티심볼 스캔, 학습 파일 영속화, MFE 트레일·TP=0, 랏/증거금 가드, O/X 디버그.

**버림 (신호 본체)**  
아시아·전일 고저 **단일** 재흡수, **H1 EMA50 기울기 필수**, 스윕 30분 창만으로 하루 후보가 1.8회에 머무는 구조.

---

## 5. 성공 정의 (V2 헌법 초안용)

1. **빈도**: 세션 가동일 20일 롤링 **중앙값 일 체결 ≥ 2**, 단일 0건일 비율 **목표 5% 미만** (포워드 측정).  
2. **생존**: EA 소프트 한도·FTMO 위반 0건 설계.  
3. **소득**: 포워드 4주 **거래당 +0.15R 이상** 없으면 실계 확대 중단 (S1과 동일 원칙).  
4. **품질**: 모든 체결은 **사전 등록된 패턴 ID + O/X 전부 O** (B-tier는 별도 명시된 완화 집합).
