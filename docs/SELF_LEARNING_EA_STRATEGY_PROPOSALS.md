# 자가학습형 EA — 전략 제안서 (3안)

**목적**: AI·기관 환경에서 20년 생존을 전제로, 거래 품질이 누적 학습으로 우상향하는 완전 자동 EA.  
**컨펌 대기**: 아래 **안 A / B / C** 중 1안 확정 후 MQL5 구현·백테스트·데모 검증 단계로 진행.

---

## 0. 공통 설계 (3안 모두 동일 탑재)

### 0.1 자가학습 코어 — «Quality Engine»

| 계층 | 역할 | 갱신 주기 |
|------|------|-----------|
| **Setup Scorer** | 진입 직전 피처(스프레드, 변동성, 세션, 레짐, 시그널 강도) → 품질 점수 0~100 | 매 틱(진입 판단 시) |
| **Outcome Learner** | 청산 후 (R배수, MFE/MAE, 보유시간) 반영, 가중치 온라인 갱신 | 매 거래 종료 |
| **Param Adapter** | 허용 범위 내에서만 미세 조정 (최소 시그널 점수, 세션 가중, 변동성 배수) | 일 1회 + N거래마다 |
| **Degrade Guard** | 최근 K거래 기대값·연속손실·품질 분포 악화 시 신규 진입 중단·알림 | 실시간 |

학습 데이터는 **터미널 로컬 CSV/SQLite**(브로커·심볼별 분리). 외부 VPS·클라우드 불필요.  
과적합 방지: **워크포워드 창**(예: 최근 200거래 학습, 그 이전은 검증만), 파라미터는 사용자 상한/하한 밖으로 나가지 않음.

### 0.2 리스크·실행 — «Execution & Guardian»

- **포인트 통일**: 모든 SL/TP/트레일링/버퍼는 `_Point` 기준 사용자 포인트(5자리 FX는 1포인트=0.00001 등 자동 환산).
- **브로커 자동감지**: `SYMBOL_DIGITS`, `SYMBOL_TRADE_TICK_SIZE`, `SYMBOL_POINT`, 서버 시간 `TimeTradeServer()`, 심볼 접미사 매칭(XAUUSD, XAUUSDm, US100 등).
- **SL Guardian**: 스프레드 급등, 틱 공백, 롤오버 전후, 금요일 마감 N분 전 신규/리스크 확대 차단; SL 최소거리·스톱레벨(`SYMBOL_TRADE_STOPS_LEVEL`) 자동 보정.
- **랏**: `LotsMode` = Fixed / Risk% / QualityScaling(품질 점수에 따라 리스크%를 0.5x~1.0x).
- **거래시간**: 세션별 On/Off + `DailyLossLimit%` 도달 시 당일 신규 진입 금지(오픈 포지션 트레일링만).
- **프랍 호환**: 일일 DD·총 DD 하드캡 입력(펀디드넥스트 스텔라 2 예: 일 -5%, 총 -10% 근처 보수 설정), 뉴스 필터 옵션, 최소 보유/과도 스캘핑 방지.

### 0.3 트레일링 (사용자 설정, 최우선)

```
TrailStartPoints     : 진입가 대비 이익 N포인트 도달 시 활성
TrailLockAtStart     : 활성 순간 SL을 (진입가 ± TrailStartPoints) 로 이동 (본절+α)
TrailStepPoints      : 이후 최고가(매수)/최저가(매도)에서 TrailStep 간격 추격
TrailMinProfitPoints : (선택) 스텝 추격 전 최소 확보 이익
```

예: `200 / 200 / 10` → +200pt 시 SL을 +200pt 라인에 고정 후, 고점 기준 10pt 스텝 트레일.

**RR 극대화 원칙**: 초기 TP는 넓게(또는 TP 없음+트레일 전용); Quality Engine이 «기대 R» 낮은 구간은 진입 거부.

### 0.4 VPS 없이 가동

- MT5 터미널 로컬 상시 구동(가정 PC/노트북) + **재연결 자동 재동기화**.
- 경량 설계(초당 1회 이하 무거운 계산, M1/M5 기준 바 이벤트 중심).
- 24시간 필수 구간(아시아·런던 오픈)은 사용자 스케줄 알림; 프랍 규정상 24h 필요 시 **브로커 무료 서버** 또는 기존 PC 상시 전원만 권장(VPS «구독» 불필요).

### 0.5 자산군 프로파일

| 프로파일 | 기본 심볼 예 | 특화 파라미터 |
|----------|--------------|----------------|
| FX | EURUSD, USDJPY | 스프레드·세션 가중 |
| Metal | XAUUSD | 변동성 배수, Guardian 강화 |
| Index | US100, US30, DE40 | 갭·RTH 필터 |
| Crypto | BTCUSD | 24/7, 스프레드 상한 엄격 |

단일 EA에 `AssetProfile` enum으로 전환; **전용 최적**은 C안(지수), B안(골드) 권장 매핑.

### 0.6 일 2회 이상 진입 보장 (품질과의 균형)

- **하한**: `MinTradesPerDay` = 2 → 품질 임계값을 시간 경과에 따라 완만히 완화(일말 1회, 최소 점수 바닥은 사용자 설정).
- **상한**: 과매매 방지 `MaxTradesPerDay`.
- 품질 우선 원칙은 유지; «억지 진입»은 Degrade Guard가 차단.

## 안 A — «Liquidity Echo MR» (유동성 잔향 평균회귀)

### 컨셉

기관·알고리즘의 **유동성 사냥(스윕)** 직후, 가격이 과도하게 이탈했다가 **단기 평균(세션 VWAP / 앵커 밴드)** 로 되돌아오는 «잔향»만 취함.  
HFT가 지배하는 초단타 주문장이 아니라 **M5~M15 홀딩**으로 겹침을 피하고, 스윕 방향 **반대**가 아닌 **과확장 후 첫 구조 복귀**에 맞춤.

### 기관/AI와의 관계

- **틈새**: L2 밀리초 단타가 아닌 «스윕 후 15~120분» 구간.
- **편승**: 스윕 자체는 기관 유동성 수집; EA는 그 직후 비효율만 수확.

### 진입 로직 (요약)

1. **레짐**: ADX 낮음·변동성 중간 = MR 허용; 강한 ADX 돌파는 Quality로 차단 학습.
2. **트리거**: 전일/세션 고저 대비 돌파 후 N바 내 `Close` 복귀(페이크 브레이크), 스프레드 정상.
3. **필터**: Quality Engine 점수 ≥ 동적 임계; 거래량 대리(틱 볼륨) 급증 후 감소 패턴.
4. **SL**: 스윕 저점/고점外 + `SL_BufferPoints`; **TP 없음 → 트레일링 전용**.

### 자가학습 포인트

- «페이크 깊이», «복귀 속도», «세션» 조합별 기대 R 학습.
- 손실 클러스터 시 **해당 세션 MR 비활성** (자동).

### 적합 자산

**FX, XAUUSD** (2순위: 크로스 FX). 지수는 갭 때문에 프로파일 조정 필요.

### 기대 운용 성격

- 승률 중~중상, R:R 트레일링으로 확대.
- 일 2~6건 목표 (런던·NY 중첩).

### 월 300만원+ 관점 (참고)

10만$ 계좌, 월 **1.5~3%** 순수익(프랍·비용 후) = 대략 1,500~3,000$; 600만원 리얼은 **고정 리스크%** 동일 전략으로 스케일. *(시장·실행 의존 — 백테스트·포워드 필수)*

## 안 B — «Session Flow Rider» (세션 기관 흐름 추종)

### 컨셉

런던 오픈·NY 오픈 전후 **방향성 유동성 이벤트**에서, 첫 **Higher-Timeframe 구조( H1 )** 와 일치하는 M5 **풀백 진입**만 실행.  
«예측»이 아니라 **이미 발생한 기관 방향**에 편승.

### 기관/AI와의 관계

- **편승**: 오픈 레인지 브레이크·연속 OHLC 구간은 CTA/데스크 플로우와 동조.
- **틈새**: 1분 브레이크아웃 경쟁 회피 → M5 구조 되돌림(50~61.8% 구간) + Quality 필터.

### 진입 로직 (요약)

1. **세션 앵커**: 브로커 시간 기준 런던/아시아 레인지 고저 산출.
2. **브레이크 확정**: M5 종가 기준 레인지 이탈 + H1 EMA50 방향 일치.
3. **진입**: 첫 M5 조정(EMA20 터치 또는 구조 FVG 리테스트); Quality 낮으면 스킵.
4. **SL**: 조정 스윙 + 버퍼; **트레일링 최우선**, TP2 옵션(부분청산은 Off 기본 — 사용자 선택).

### 자가학습 포인트

- 세션별(아시아-only vs LD/NY) 승률·R 분포 학습 → **캘린더 가중 자동**.
- 뉴스 전후 변동성 클러스터에서 `TrailStartPoints`·`TrailStep` 어댑터(상한 내).

### 적합 자산

**XAUUSD, US100/US30, EURUSD, GBPUSD** — **골드·지수 전용 프리셋** 권장.

### 기대 운용 성격

- 승률 중, **대형 트레일**로 RR 극대.
- 일 2~4건 (세션 집중).

### 프랍 메모

펀디드넥스트: 오버나이트·뉴스 규정 확인 후 `NewsGuardianMinutes` 기본 On.

## 안 C — «Volatility Spine Swing» (변동성 척추 스윙, 지수·골드 특화)

### 컨셉

**ATR 밴드 + 시장 미시구조 프록시(연속 동일 방향 바 수, 틱 속도)** 로 «과열»만 추적 진입.  
지수·골드처럼 **세션 변동성이 큰 상품**에서 기관 옵션·헤지 플로우가 만드는 **추세 스파인**을 타고, 횡보는 Quality+레짐으로 거의 미거래.

### 기관/AI와의 관계

- **틈새**: 초단기 MM과 달리 **M15~H1 스윙**, 틱 예측 없음.
- **편승**: 변동성 확대 국면은 옵션 딜러·패시브 펀드 리밸런싱과 동조되는 추세 구간.

### 진입 로직 (요약)

1. **Spine**: M15 EMA100 기울기 + ATR(14) > 롤링 중앙값.
2. **Pullback**: M5이 Spine 쪽으로 ATR의 0.3~0.6배 되돌림; RSI 극단만 보조(단독 사용 안 함).
3. **확인**: 되돌림 종료(엔걸핑/구조 고저) + Quality ≥ 임계.
4. **SL**: 스윙 + `SL_GuardianSpreadMult` × 스프레드; 트레일만으로 수익 확장.

### 자가학습 포인트

- ATR 구간·요일·지수 vs 골드 **프로파일 자동 분리 학습**.
- MAE가 큰 패턴(예: 첫 30분 역행) 피처 가중치 상향 → 진입 거부 강화.

### 적합 자산

**US100, US30, XAUUSD 1순위**; FX는 프로파일 «LowVol»로만 제한 운용.

### 기대 운용 성격

- 빈도: 변동성에 따라 **일 1~5건** (MinTrades 완화 규칙으로 2건 하한 보조).
- **RR·트레일링 극대**에 최적화된 안.

## 추천 (컨펌용 의견)

- **복수 자산·프랍+리얼·트레일링 최우선·기관 편승**을 한 번에 맞추려면 → **안 B** 또는 **안 C**.
- **월 안정적 빈도 + FX 비중**이 크면 → **안 A** 보조 또는 혼합(멀티 매직넘버는 비권장, 단일 Quality Engine 권장).

**1차 구현 추천: 안 B (골드+US100 프리셋)**  
이유: 요구 RR/트레일링·일 2건·기관 편승·프랍 규칙을 가장 직관적으로 만족.

**대안: 안 C** — 지수/골드 전용 단일 상품 집중 시 기대값·트레일 효율이 가장 좋을 가능성.

**안 A** — 포트폴리오 분산 시 B/C와 **다른 레짐** 담당 시 상호 보완.

## 컨펌 시 필요 정보

1. 선택 안 (A / B / C 또는 B+C 레짐 스위치).
2. 우선 브로커·심볼 정확 명칭 (예: FundedNext MT5 `XAUUSD`, `USTEC`).
3. 기본 포인트 프리셋 (Trail 200/200/10 유지 여부).
4. MT5 전용 여부 (MQL5).
5. 뉴스 필터: 완전 차단 vs Guardian만.
