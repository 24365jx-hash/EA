## 10. 트레일링 작동 확인 (최우선)

### 사용자 명령
> Start 200: 진입점으로부터 200pt 되는 즉시 SL → **진입점으로부터 200pt 지점**  
> 이후 Step(예:10): **최초 이동한 200pt 지점부터** 10pt 간격 추격

### 코드 (L517–547)

```
if profit < Start: return
steps = floor((profit - Start) / Step)
lock_pts = Start + steps * Step
BUY : SL = Open + lock_pts
SELL: SL = Open - lock_pts
```

| profit | lock_pts | BUY SL | 명령 | 판정 |
|--------|----------|--------|------|------|
| 199 | (미발동) | 초기 SL | 유지 | **OK** |
| 200 | **200** | Open+200 | 진입±200 즉시 | **OK** |
| 209 | 200 | Open+200 | 200 유지 | **OK** |
| 210 | **210** | Open+210 | 200지점+10 | **OK** |
| 220 | **220** | Open+220 | +20 | **OK** |
| 231 | **230** | Open+230 | floor | **OK** |

| 금지 해석 | 코드 잔존 | 판정 |
|-----------|-----------|------|
