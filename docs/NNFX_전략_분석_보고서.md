# NNFX (No Nonsense Forex) 전략 분석 보고서

## 1. 개요

**NNFX**는 **No Nonsense Forex**의 약자로, 트레이더 **VP(Patrick)**가 제시한 **규칙 기반·지표 기반 추세 추종 프레임워크**다.  
단일 “만능 지표”나 주관적 가격 행동(Price Action) 해석에 의존하지 않고, **역할이 명확한 지표 조합 + ATR 리스크 관리 + 백테스트**로 의사결정을 기계화하는 것이 핵심이다.

| 항목 | 내용 |
|------|------|
| 성격 | 규칙 기반 추세 추종 시스템 |
| 주 타임프레임 | **일봉(D1)** |
| 의사결정 방식 | 지표 역할 분리 + 체크리스트(Decision Tree) |
| 리스크 축 | **ATR(14)** 기반 SL/TP/포지션 사이징 |
| 지표 고정 여부 | **고정 안 함** — 역할만 정의, 구체 지표는 백테스트로 선택 |

> NNFX는 “완성된 시그널 서비스”가 아니라 **알고리즘을 스스로 설계·검증하는 방법론**이다. VP 본인도 실제 사용 지표/설정을 공개하지 않는다.

---

## 2. 전략의 철학

1. **주관성 제거** — “차트가 좋아 보인다” 대신 “규칙이 맞다/아니다”로 판단한다.
2. **역할 분리** — 한 지표가 진입·필터·청산을 동시에 담당하지 않는다.
3. **통계적 우위** — 한 번의 완벽한 셋업이 아니라, **반복 가능한 규칙의 장기 기대값**을 본다.
4. **뉴스 회피** — 경제지표/뉴스에 의한 돌발 변동을 전략 핵심으로 쓰지 않는다.
5. **완성된 시스템** — 진입뿐 아니라 **필터, 청산, 자금관리, 테스트**까지 한 세트로 본다.

## 3. 알고리즘 구성 요소 (6개 축)

NNFX 알고리즘은 보통 아래 6개 역할로 구성된다.

```
[ATR] ── 변동성·리스크 기준
   │
[Baseline] ── 방향 필터 (매수/매도 허용 측)
   │
[C1] ── 주 확인 / 셋업 시그널
   │
[C2] ── 보조 확인 (C1과 독립적인 측정이 이상적)
   │
[Volume / V1] ── 품질 필터 (약한 셋업 제거)
   │
[Exit] ── 아이디어 무효화 / 잔여 포지션 청산
```

### 3.1 ATR (Average True Range)

- 기본: **ATR(14)**, **직전 완성봉** 기준 계산
- 용도: 방향 예측이 아니라 **SL/TP 거리, 포지션 크기, Baseline 근접도(1×ATR)** 측정
- 변동성이 커지면 손절 폭·로트가 함께 조정되어 시장 환경에 맞게 리스크를 정규화한다

### 3.2 Baseline (기준선)

- 주로 MA류(예: KAMA, SMA 등) 라인 지표
- **가격이 Baseline 위면 롱 허용, 아래면 숏 허용** (방향 필터)
- 추가 조건: 가격이 Baseline에서 **1×ATR 이상 멀면** 표준 진입을 보류(과확장)
- Baseline 자체는 “흥분시키는” 시그널이 아니라 **노이즈를 줄이는 필터**다

### 3.3 C1 (Main Confirmation)

- **주 진입 셋업**을 만드는 지표
- Baseline이 허용한 방향과 일치해야 한다
- 선택 과정이 엄격함: 후보 다수를 짧게 스크리닝 → 상위 소수만 장기 백테스트 → 최종 C1 확정
- C1만으로 진입하지 않는다. 체크리스트의 **시작점**이다

### 3.4 C2 (Second Confirmation)

- C1과 **다른 성격**의 확인 지표가 이상적 (동일 측정치 복제는 가치 낮음)
- C1 신호를 “한 번 더” 검증해 과신을 줄인다
- C2 역시 백테스트로 선택한다

### 3.5 Volume Indicator (V1)

- 진입 트리거가 아니라 **품질 필터**
- Baseline + C1 + C2가 맞아도 거래량이 동의하지 않으면 패스
- 예시로 거론되는 유형: VPCI 등 (가격·거래량 일치 여부 측정)

### 3.6 Exit Indicator

- “얼마를 먹었나”가 아니라 **원래 셋업이 아직 유효한가**를 판단
- Exit 신호가 나오면 잔여 포지션을 시스템 규칙에 따라 청산
- 예: Waddah Attar Explosion, Parabolic SAR 등 (역할만 맞으면 후보)

## 4. 진입 유형 (Entry Types)

NNFX는 단순 1가지 진입이 아니라, 상황에 따라 **여러 진입 경로**를 둔다.

### 4.1 Standard Entry (표준 진입)

1. **C1이 시그널**을 준다
2. Baseline이 같은 방향에 **동의**
3. 가격이 Baseline **1×ATR 이내**
4. C2 동의
5. Volume(V1) 동의
6. **7-Candle Rule**: C1 시그널이 **7봉 이내**여야 유효

### 4.2 Baseline Cross Entry (기준선 교차 진입)

1. 가격이 Baseline을 **가로질러 종가 마감** (교차 시그널)
2. C1·C2·V1이 동의
3. 가격이 Baseline **1×ATR 이내**

### 4.3 Pullback Entry (되돌림 진입)

1. Baseline을 큰 캔들로 돌파하며 **1×ATR 밖으로** 종가
2. **다음 봉**에서 가격이 다시 **1×ATR 안**으로 들어와 종가하면 진입 후보
3. 필터(C1/C2/V1) 동의 확인

### 4.4 Continuation Entry (지속 진입)

1. 이전에 유효한 진입(또는 자금관리로 놓친 신호)이 있었음
2. Baseline이 아직 반대 교차하지 않음
3. 가격이 Baseline에서 **1×ATR 이상** 떨어져 있음
4. C1이 새 시그널을 주면 추세 지속 진입으로 검토

### 공통 타이밍 규칙

| 규칙 | 의미 |
|------|------|
| **1-Candle Rule** | 시그널 직후 필터가 안 맞으면, **다음 1봉**까지 재확인. 그 이상 미루지 않음 |
| **7-Candle Rule** | C1 시그널이 **7봉보다 오래되면** 셋업 만료 (“Bridge too far”) |
| **완성봉만 사용** | 진행 중 봉이 아니라 **직전 완성봉** 기준 |

## 5. 자금관리·트레이드 매니지먼트

NNFX의 차별점은 진입만큼 **리스크 구조**에 있다.

### 5.1 기본 리스크 파라미터 (커뮤니티 표준)

| 항목 | 값 |
|------|-----|
| 총 리스크/트레이드 | 약 **2%** (주문 2개로 분할) |
| 주문 #1 | 리스크 **1%**, SL **1.5×ATR**, TP **1×ATR** |
| 주문 #2 | 리스크 **1%**, SL **1.5×ATR**, TP 없음(Exit/트레일로 관리) |
| ATR | **14** |

### 5.2 포지션 관리 흐름

```
진입 (주문1 + 주문2)
        │
        ├─ 주문1이 1×ATR TP 도달
        │     → 주문1 청산 (계좌 리스크의 절반 실현)
        │     → 주문2 SL을 본전(BE)으로 이동
        │
        ├─ 주문2가 +2×ATR 도달
        │     → 트레일링 SL 활성화 (보통 1.5×ATR)
        │     → 이후 +0.5×ATR마다 트레일 조정
        │
        └─ Exit / Baseline 반대 교차 / C1·C2 반대 시그널
              → 잔여 포지션 청산
```

### 5.3 설계 의도

- **절반 익절 + 본전 이동**으로 심리·계좌 리스크를 먼저 줄인다
- **나머지 절반**은 추세를 길게 타도록 남겨 승률보다 **손익비·추세 포착**을 노린다
- ATR로 손절 폭이 달라지므로, 같은 % 리스크를 유지하려면 **로트가 ATR에 반비례**한다

## 6. 의사결정 트리 (요약)

```
완성봉 마감
   │
   ▼
Baseline이 방향을 허용하는가?
   │ 아니오 → 대기
   ▼ 예
C1 셋업이 있는가? (7봉 이내)
   │ 아니오 → 대기 / 다른 진입 유형 검토
   ▼ 예
가격이 Baseline 1×ATR 이내인가? (표준 진입 기준)
   │ 아니오 → Pullback/Continuation 규칙으로 분기
   ▼ 예
C2 동의?
   │ 아니오 → 1-Candle Rule로 1봉만 대기 후 재확인
   ▼ 예
Volume 동의?
   │ 아니오 → 패스
   ▼ 예
ATR 기반 2분할 진입 (SL 1.5×ATR)
   │
   ▼
TP1 / BE / Trail / Exit 규칙으로 관리
```

## 7. 다른 FX 전략과의 비교

| 구분 | NNFX | 고전 PA/패턴 | 스캘핑/인traday | 마틴게일/그리드 |
|------|------|-------------|-----------------|-----------------|
| 주 타임프레임 | D1 | 다양 | M1~H1 | 다양 |
| 의사결정 | 규칙·지표 역할 | 주관적 해석 | 속도·체결 | 복구·격자 |
| 리스크 | ATR 고정 비율 | 가변 | 좁은 손절 | 손실 확대 위험 |
| 강점 | 검증 가능, 체계적 | 유연 | 기회 빈도 | 단기 회복 시도 |
| 약점 | 신호 적음, 래그 | 일관성 부족 | 비용·과매매 | 폭락 시 파산 위험 |
| EA화 | 적합 (규칙 명확) | 어려움 | 가능하나 민감 | 위험 높음 |

**요약:** NNFX는 “자주 치는” 전략이 아니라 **일봉에서 필터를 많이 걸고, 맞을 때 ATR로 리스크를 정규화해 추세를 먹는** 쪽에 가깝다.

## 8. 강점과 한계

### 강점

- 체크리스트로 **재현성·백테스트 가능성**이 높다
- 진입·필터·청산·자금관리가 **한 프레임**에 묶여 있다
- ATR로 **페어/변동성 차이를 정규화**한다
- EA/테스터 자동화에 잘 맞는다 (역할별 인디케이터 스왑)

### 한계

- **지표 선택은 트레이더 책임** — 공개 만능 조합이 없다
- 일봉 추세 전략이라 **횡보·저변동**에서 기대값이 떨어질 수 있다
- 확인 지표가 겹치면(상관 높음) 필터가 사실상 무력화된다
- 백테스트 과최적화(오버피팅) 위험이 크다
- 완성봉 대기 → **신호 지연(래그)** 은 본질적 특성이다

## 9. 백테스트·알고리즘 구축 실무 가이드

권장 순서:

1. **C1 후보 스크리닝** — 다수 지표 × 기본/느슨/타이트 설정, 짧은 기간·소수 페어
2. **상위 C1 심화 테스트** — 더 긴 기간으로 안정성 확인
3. **Baseline 선택** — C1과 조합해 방향 필터 효과 측정
4. **C2 추가** — C1과 상관·중복이 낮은 지표 우선
5. **Volume·Exit 결합** — 전체 Decision Tree로 재검증
6. **ATR MM 고정** — SL/TP/분할/트레일 규칙을 바꾸지 말고 먼저 측정
7. **포워드 테스트** — 실계좌 전 소액/데모로 규칙 준수 여부 확인

주의:

- 한 지표만 바꿔도 전체 기대값이 바뀐다 → **부분 최적화가 아닌 전체 알고리즘**으로 평가
- “예쁜 차트 예시”가 아니라 **규칙 일관성·샘플 수·시장 국면**을 본다

## 10. EA 구현 관점 체크리스트

이 저장소(EA) 맥락에서 NNFX를 자동화할 때 최소 요구사항:

- [ ] D1 **완성봉** 기준 시그널만 평가
- [ ] 역할별 인디케이터 슬롯: Baseline / C1 / C2 / Volume / Exit / ATR
- [ ] 진입 모드: Standard / Baseline Cross / Pullback / Continuation
- [ ] 1-Candle Rule, 7-Candle Rule, 1×ATR Baseline 근접 규칙
- [ ] 2분할 주문: TP1(1×ATR) + BE 이동 + 2×ATR 이후 트레일
- [ ] Exit / Baseline 반대 교차 / 반대 C1·C2에 의한 잔여 청산
- [ ] 리스크 % → ATR 거리 기반 로트 계산
- [ ] 백테스트/테스터에서 인디케이터 조합을 쉽게 교체 가능

---

## 11. 결론

NNFX는 “어떤 지표를 쓰느냐”보다 **지표에 역할을 부여하고, ATR로 리스크를 고정하며, 백테스트로 조합을 검증하는 프레임워크**다.

- **한 줄 정의:** 일봉 추세 추종 + 다층 확인 필터 + ATR 2분할 자금관리  
- **적합 대상:** 규칙·검증을 선호하고, 신호 빈도보다 프로세스 일관성을 중시하는 트레이더/EA 개발자  
- **부적합:** 고빈도 매매, 뉴스 트레이딩, 주관적 차트 해석을 즐기거나, “바로 쓸 완성 시그널”을 원하는 경우  

실무적으로는 **역할 슬롯을 고정한 뒤 지표만 갈아끼우며 전체 트리를 테스트**하는 방식이 NNFX의 본래 취지에 가장 가깝다.
