## 2. 진입 규칙

### R01 — 인사이드 바
- `H2 < H1 AND L2 > L1` (**완전 포함, 등호·터치 불가**)
- #2가 #1보다 작음 (위 식으로 자동)
- **캔들 색 완전 무관**

### R02 — 전제
- R01 충족 시에만 이후 진행

### R03 — 진입 트리거 (종가 돌파만)
- Close > #2 High → **BUY** / Close < #2 Low → **SELL**
- 심지만 돌파·종가 미돌파 = 무효
- 돌파 방향도 **색 무관**

### R03c — 돌파봉 #3 몸통
- `body = |Close−Open|` (색 무관)
- **통과: body > upper AND body > lower** 만
- **심지 합 비교 금지** (v1.04 과필터 버그)

### R04 — 타임아웃
- #2 **직후 1봉(#3)** 만 유효
- #3가 #2 범위를 종가 돌파하지 않으면 **셋업 취소**
- #4 이후 대기 **없음**

### R05 — 포지션
- 보유 중 **추가 진입 금지** (동시 1포지션)

### R06 — 청산
- **TP 없음** (항상 0)
- **초기 SL** + **트레일링**만 사용

## 3. 트레일링 (사용자 명령 락 — BE 금지)

예: Start=200, Step=10

| 수익(points) | SL (BUY) |
|--------------|----------|
| < 200 | 초기 SL 유지 |
| ≥ 200 | **진입점 + 200** (즉시) |
| ≥ 210 | 진입점 + 210 |
| ≥ 220 | 진입점 + 220 |
| … | 최초 200pt 지점부터 Step 간격 추격 |

공식 (BUY):  
`lock = Start + floor((profit − Start) / Step) × Step`  
`SL = Open + lock`  
(SELL: `Open − lock`)

**금지:** SL을 진입가(본전/0)로 옮기는 해석.  
명령: “200포인트 되는 즉시 SL은 진입점으로부터 **200포인트 지점**으로 이동”.
