## 3️⃣ 신규 전략 3안 (V2, 기존 B와 **별개 논리**)

### 안 **V2-α** — «비용 장벽 세션 연속» (Cost-Hurdle Session Continuation, **CHSC**)

**한 줄:** 변동성이 **실제로 큰 날만**(E1·E2), **스프레드 대비 기대 R이 비용을 넘는 날만** 진입(E3).

| 항목 | 내용 |
|------|------|
| **엣지 가설** | 런던 이후 변동성 상승 구간에서 **H1 방향 유지** 확률이 무작위 대비 우위 — *단, 크기는 Krueger급 **소폭**일 수 있음* |
| **진입** | ① 아시아 고저(서버시, 입력) ② **ATR(14) M5 ≥ 60일 중앙값** ③ 런던·NY 허용창 내 M5 종가가 아시아 돌파 ④ H1 종가·EMA(50) 동방향 ⑤ **(예상 MFE − SL) / SL ≥ K** (K는 **스프레드+슬리피지 포인트 환산 후** 최소 1.5, 검증으로 조정) |
| **청산** | TP=0, **트레일 200/200/10**(포인트, 입력) |
| **빈도** | 변동성 필터로 **일 0~4건** 가변 → **월 평균 일 2건**은 V4로 검증 |
| **기관** | M5, 세션 편승(E1) |
| **월 300만** | **합격은 V2만으로 판정**. 본 안은 «후보」 |

**근거:** E1+E2 (세션·변동성). **없는 근거:** «CHSC = 월 2.22%» (백테 필요).

---

### 안 **V2-β** — «이중 세션 모멘텀 필터» (Dual-Session Momentum Filter, **DSMF**)

**한 줄:** **아시아 레인지 + 런던 첫 2시간 방향**이 일치할 때만 **NY 구간** M5 풀백 1회 — 빈도↓, **트레일로 R 확대 시도**.

| 항목 | 내용 |
|------|------|
| **엣지 가설** | 유럽·미국 **연속 방향** 시 당일 추세 지속 가능성 — 문헌상 **갭·세션 연계**(E2), 방향 지속은 **검증 대상** |
| **진입** | ① 런던 2h 박스 방향 = 매수/매도 바이어스 ② NY 창에서만 ③ M5 EMA(20) 터치 + 방향봉 ④ Quality 점수 ≥ 동적 하한(일 2건 미달 시 완화, **일 DD 내**) |
| **청산** | 스윙 SL(포인트) + 트레일 우선 |
| **빈도** | **2~3건/일** 목표 (양방향 동시 금지) |
| **월 300만** | V2 검증 필수; **이론상** 건당 R↑·건수↓ 트레이드오프 |

**근거:** E1·E2.**反증 가능:** E4 (유사 돌파계열 OOS 약세).

---

### 안 **V2-γ** — «실행비용 최저 구간 스나이퍼» (Low-Cost Window Sniper, **LCWS**)

**한 줄:** **스프레드·거래량 조건**(E1: 유동성 좋은 US 시간) 만족 시에만 거래, **일 최소 2건**은 «약한 신호 2건»이 아니라 «**동일 바 2심볼 금지·1심볼 2세트업**» — *주력 USTEC, 보조 XAU(컨펌)*.

| 항목 | 내용 |
|------|------|
| **엣지 가설** | 수익의 적은 **gross 엣지**(E3)를 **비용 최소 창**에서만 수확 |
| **진입** | ① `InpMaxSpreadPts` 이하만 ② US cash **14:30–17:30 서버(브로커 보정 입력)** ③ 돌파+풀백 간소 규칙 ④ **진입 전 (스프레드+슬리피지) &lt; 0.15 × SL포인트** |
| **리스크** | 잔고 **0.5~0.8%/건**(입력 상한, 프랍 DD) |
| **월 300만** | 빈도·R 모두 **보수적 가정** → **V2 통과 난이도 가장 높음**, 대신 **E3·E4와 정합** |

**근거:** E3·E4·E5 (비용이 전략을 지운 사례). **명시:** 월 300만 **보장 아님**, «비용 현실 반영» 안.
